## 7. 已确定的架构和产品决策

- M1-A 已完整验收通过；窗口只能由终端用户明确选择，扫描、单候选、标题或进程名匹配均不得自动选择。

- CandidateId 与 SelectionId 保持隔离；刷新和取消均清除旧选择，程序重启不能恢复旧原生句柄。
- 标题、PID、进程名或 HWND 均不能单独证明窗口身份；M1-B 必须重新验证组合窗口与进程身份。
- 当前不支持 GTA Online，不自动识别或选择 GTA，不捕获，不 armed，不发送输入，不自动提权，不创建 Windows Service。
- M1-B 不得提前实现 Windows Graphics Capture、Capture Target/Input Target 的输入资格、安全 armed 或 `SendInput`。
