# Public Repository Checklist

本仓库保持公开。此清单用于每次推送、可见性复核以及 M9 发布审计；公开仓库包括源码、完整 Git 历史、Issue/PR 附件和 GitHub Actions 产物。

当前没有 `LICENSE`。在项目维护者明确选择并添加代码许可证前，本仓库只能描述为“公开可见源码”，不得称为开源项目，也暂不接受需要合并代码的外部贡献。

## 每次推送前

- [ ] 已确认当前远程仓库仍为 Public，且本次推送不包含意外分支、标签或生成产物。
- [ ] `git status` 中的每个新增、修改和删除文件都属于本次授权范围。
- [ ] 已检查当前工作树、暂存区和待推送提交中不存在维护者 Key、用户 Key、密码、令牌、连接字符串、证书私钥或其他凭据。
- [ ] 已运行 `dotnet run --project tools/GtaAutoGameplay.RepositoryGuard --configuration Release -- --repository . --history --allowlist tools/repository-guard.allowlist.json`，并处理所有失败项；没有把自建规则误当作完整秘密审计的替代品。
- [ ] 远程 URL、脚本、配置模板和测试数据中没有嵌入凭据。
- [ ] `.env`、本地秘密配置、凭据文件、日志、转储、截图、录像、存档、用户配置和缓存均被 `.gitignore` 排除。
- [ ] 示例配置只包含明显不可用的占位符，不包含真实或看似可用的 Key。
- [ ] 本次变更没有游戏本体、游戏可执行文件、用户存档、账户信息或未经授权的游戏素材。
- [ ] 新增测试夹具属于自制、合成或已明确授权的公开夹具，并在 `tests/fixtures/README.md` 要求的清单中记录来源与许可证。
- [ ] 新增依赖、模型、数据集、字体、图标或素材已经登记到 `docs/THIRD_PARTY_INVENTORY.md`。
- [ ] README 仍准确说明 GTA V Windows 离线故事模式范围、GTA Online 禁止、BYOK、本地模式边界、非官方身份和当前开发阶段。
- [ ] 没有未经验证的 GTA VI、任务覆盖率、识别准确率或完整自动通关声明。

## Git 历史和 GitHub 托管内容

- [ ] 已使用能够扫描完整历史的工具检查所有本地可达分支和标签，而不是只扫描当前工作树。
- [ ] CI 扫描使用完整 Git 历史，扫描输出对疑似秘密进行 redact。
- [ ] `.github/workflows/repository-security.yml` 仍保持 `contents: read` 最小权限、完整历史 checkout、关闭凭据持久化，并把每个第三方 Action 固定到已审核的 40 位提交 SHA。
- [ ] 如发现真实凭据，先由凭据所有者吊销或轮换，再处理历史；仅删除当前文件不视为修复。
- [ ] 已检查 GitHub Issue/PR 正文与附件、Actions 日志与产物、缓存及历史 Releases 中没有凭据或受限资源。
- [ ] GitHub Actions 使用最小权限；第三方 Action 固定到经过审核的版本或提交。
- [ ] 不在 CI 中使用维护者 Key 为终端用户功能提供测试或默认服务。

## 依赖、模型、数据和许可证

- [ ] 所有第三方项均记录名称、类型、精确版本、官方来源和许可证。
- [ ] 已确认修改权、源码再分发权、二进制/模型再分发权及通知义务。
- [ ] 所有传递依赖和随包资源均已纳入审查。
- [ ] 原始 GTA 截图、录像和由其直接制作的未授权模板只保存在贡献者本机的忽略目录中。
- [ ] 公开测试数据不包含终端用户账户名、桌面通知、存档、个人信息或其他应用内容。
- [ ] 第三方攻略只提取运行所需的结构化事实，不复制全文。
- [ ] 当前许可证状态在 README 中描述准确；没有 `LICENSE` 时不使用“开源项目”或“开源发布”。

## M9：安装包和发布产物

以下项目只在准备任何公开安装包时执行，包括 Developer Preview 安装包：

- [ ] 已完成 M9 中全部适用检查，并确认公开源码不等于正式安装版。
- [ ] 安装包、便携包、模型、配置模板和 Release 附件已经单独执行凭据与受限资源扫描。
- [ ] 已生成并审核依赖清单、模型/数据清单、第三方许可证通知和 SBOM（若发布流程采用）。
- [ ] 所有进入安装包的第三方组件和模型均允许再分发。
- [ ] 已在干净的标准用户 Windows 账户中测试安装、首次启动、升级、卸载和快捷方式。
- [ ] 已验证紧急停止、输入账本释放、凭据删除、日志保留和用户数据删除语义。
- [ ] 已明确代码签名策略；未签名测试版有清晰提示，且文档不指导绕过 Windows 安全警告。
- [ ] 若未来实现自动更新，已验证其签名、来源、失败回退和禁用路径；未实现时该项标记为不适用。
- [ ] Release 包含版本化文件名、发布说明和 SHA-256 校验文件。
- [ ] `Source code.zip` 没有被描述为安装程序。

## 审核记录

每次公开发布审计应记录日期、审核人、目标提交、目标版本、使用的扫描工具及版本、发现的问题和处理结果。不得在审核记录中粘贴真实秘密值。
